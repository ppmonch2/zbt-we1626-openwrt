# Dacha Heat Bridge: OpenWrt для ZBT WE1626

**Экспериментальный проект. Подготовленные файлы пока не проверены на конкретном роутере.**

## Сборки

Автоматизированная сборка OpenWrt 25.12.6 (ramips/mt7620) включает три варианта:

1. `heat-lite` — профиль `zbtlink_zbt-we2026`, образ `sysupgrade.bin`, без LuCI.
2. `heat-webui` — тот же профиль, образ `sysupgrade.bin`, с LuCI.
3. `omni2-firstflash` — профиль `zyxel_keenetic-omni-ii`, **отдельный файл `factory.bin`** с заголовком и завершающим блоком ZyXEL Keenetic Omni II. Потенциальный формат для перехода из установленной NDMS, но **аппаратная совместимость ZBT WE1626 не подтверждена**.

Каждый образ включает: драйвер ZTE USB CDC Ethernet, поддержку FAT32/USB-флешек, Dacha Heat Bridge (локальный интерфейс для четырёх нагревателей), UCI-конфигурацию, Mosquitto без TLS.

**Управление настоящими BALLU не включено.** Локальный протокол Transformer DI 4.0 и обратные подтверждения ещё не проверены. Встроенный интерфейс пока демонстрационный: данные сохраняются на роутере.

## Пароли: только личный чат, никогда GitHub

На первом запуске OpenWrt ожидает **личную** FAT32-флешку с файлом `DACHA.TXT`. По нему настраиваются Wi-Fi `DachaHeat-Setup` и root-пароль. В публичный код, Actions и ZIP-артефакты **не включаются пароли или их хеши**. `DACHA.TXT` создаётся отдельно и передаётся владельцу в чате.

## Главные ограничения

- Физическая плата ZBT WE1626 и заводская ZyXEL Keenetic Omni II могут иметь различия. Совпадение названия прошивки и формата `factory.bin` **не гарантирует удачного запуска**.
- Образы `sysupgrade.bin` **не предназначены для первоначальной установки через Keenetic**.
- Одного резервного `firmware`/ `startup-config` недостаточно для восстановления повреждённого загрузчика и раздела калибровок Wi-Fi.
- Первый запуск через флешку решает **первоначальную настройку Wi-Fi**, но **не производит прошивку из USB**. Для прошивки из USB понадобился бы специальный ранее установленный загрузчик.
- Интернет Билайна может требовать ручной настройки сетевого интерфейса (`usb0`/другое имя). Белый список мобильной сети не гарантирует удалённого доступа из Москвы.
- Дальнейшие физические действия — только при осознании возможности полного отказа роутера и необходимости восстановления через Ethernet/UART.

Результаты проверки — GitHub Actions → Artifacts. Пароли и конфигурации пользователей сюда не загружать.
