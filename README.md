# Экспериментальная сборка OpenWrt для ZBT WE1626

**НЕ ПРОШИВАТЬ собранный .bin.** Этот репозиторий содержит только воспроизводимую диагностическую сборку.

Цель: образ OpenWrt 25.12.6 для профиля `zbtlink_zbt-we2026` (аппаратно близкий к WE1626) с USB CDC Ethernet для модема ZTE. Совместимость с конкретной платой, загрузчиком и модемом не подтверждена.

Известная конфигурация: ZBT WE1626, NDMS 2.08(AAUS.4)C2 (Keenetic Omni II), USB-модем ZTE / Билайн, 8 МБ flash и 64 МБ RAM предположительно. Сохранённые `firmware` и `startup-config` НЕ заменяют резервную копию загрузчика и калибровок Wi-Fi.

Автоматизация GitHub Actions собирает варианты **minimal** и **webui** с драйвером `kmod-usb-net-cdc-ether`, проверяет SHA256 ImageBuilder и выводит диагностические файлы в Actions → Artifacts. В сборках нет Wi-Fi паролей, настроек модема, MQTT и интеграции BALLU. Без дополнительных настроек точка доступа Wi-Fi может быть выключена.

⚠️ Из Keenetic NDMS нельзя считать безопасной запись OpenWrt `sysupgrade.bin` через пункт замены `firmware`. Требуются проверенные ревизия платы, разметка флеш, способ первичной установки и аварийного восстановления через Ethernet/U-Boot. Пока этих данных нет, никакие собранные файлы на роутер не загружать.

**Этот репозиторий публичный.** Не публикуйте пароли, файл `startup-config`, токены HOMMYN/Яндекса или другие секреты.
