# Первый вход с Android без LAN и без пароля Wi-Fi

Это инструкция **после успешной установки** экспериментальной прошивки. Она не заменяет проверку совместимости ZBT WE1626 с образом Keenetic Omni II factory.

## Какой доступ предусмотрен

- Wi-Fi: `DachaHeat-Setup` — **открытая сеть**, пароль Wi-Fi не нужен.
- Адрес управления роутером: `http://192.168.1.1`.
- LuCI: только в образах с `webui`.
- Администратор: `root`, первоначальный пароль OpenWrt отсутствует. **Сразу установите пароль**, иначе любой поблизости сможет зайти в настройки по открытому Wi-Fi.
- WAN модема ZTE и сервер Dacha Heat Bridge **изначально отключены**. Это предотвращает раздачу интернета через открытую сеть до настройки защиты.

## Первоначальная настройка с телефона

1. После первой загрузки OpenWrt подождать 2–5 минут. Найти сеть `DachaHeat-Setup` и подключить Android; предупреждение «нет интернета» здесь ожидаемо.
2. Открыть `http://192.168.1.1`. В LuCI открыть **System → Administration**, задать собственный пароль администратора `root`.
3. В **Network → Wireless** поставить WPA2-PSK или WPA2/WPA3 и пароль Wi-Fi. При желании заменить SSID и пароль на те, к которым ранее подключались BALLU и Алиса, чтобы устройства не пришлось переподключать вручную.
4. Подключиться к уже защищённой Wi-Fi-сети заново. Только после этого включать интерфейс `wanusb` в **Network → Interfaces**, подсоединить ZTE-модем и проверить доступ в интернет. В зависимости от драйвера имя интерфейса может быть `usb0` или иным. Помощник hotplug пытается подобрать CDC Ethernet после разрешения WAN.
5. С защищённого Wi-Fi администратор может включить локальный сервер командой `heatbridge-enable` по SSH, затем открыть `http://192.168.1.1:8765/`. Реальные команды на BALLU пока отключены.

Новая открытая сеть **не соответствует** паролю и имени старой сети. До перенастройки Wi-Fi четыре обогревателя и Алиса потеряют соединение с роутером. Это не означает, что их локальные термостаты обязательно перестанут нагревать; но облачное и голосовое управление может пропасть.

## Если сеть не появилась

Не повторять прошивку наугад. Причины могут включать несовпадение ревизии платы ZBT, загрузчика и образа, а также настройки Wi-Fi-драйвера. Восстановление через проводной UART/Ethernet у IT-специалиста описано в `RECOVERY_RU.md`.

## Важные ограничения

`omni2-firstflash-webui` — отдельный экспериментальный заводской образ `factory.bin`, ориентированный на формат нынешней Keenetic Omni II, **не подтверждённый на плате WE1626**. `sysupgrade.bin` для WE2026 нельзя использовать как файл первой установки через NDMS.

Публичный GitHub не содержит личных паролей. После первой настройки не оставляйте открытый Wi-Fi с пустым паролем администратора.
