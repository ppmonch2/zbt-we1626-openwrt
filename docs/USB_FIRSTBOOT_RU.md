# Настройка после первого запуска без LAN

**Эти действия выполняются только после подтверждённой установки совместимой OpenWrt.** Скрипт не умеет сам перепрошивать Keenetic из USB.

## Как передать пароли, не раскрывая их в GitHub

В публичном репозитории, GitHub Actions и общем архиве прошивки паролей нет. Файл `DACHA.TXT` создаётся отдельно и передаётся владельцу лично через чат. **Никогда не загружать его в GitHub.**

Формат файла (пример, не настоящие значения):

```text
DACHA-V1
WIFI_SSID=Keenetic-example
WIFI_PSK=XXXXXXXXXXXXXXXXXXXXXXXX
ROOT_SHA512=$6$abcdefghijklmnop$aaaaaaaaaaaaaaaa...
```

**Чтобы BALLU и Алиса не потеряли Wi-Fi:** укажите в `WIFI_SSID` точное имя прежней сети, а в `WIFI_PSK` — **её существующий пароль**, а не новый. Наша прошивка не умеет переподключать эти устройства сама. Если имя/пароль не совпадут, придётся перепривязывать их вручную. Оба значения передаются владельцу только через личный чат/USB, не GitHub.

В корне FAT32-флешки файл должен называться строго `DACHA.TXT`. Остальные данные на флешке лучше временно убрать.

## На даче: один USB-порт

1. Сохранить файл `DACHA.TXT` из личного чата на FAT32-флешку с Android через USB-OTG.
2. **Перед первой загрузкой OpenWrt** выключить питание роутера, извлечь модем ZTE и поставить флешку с `DACHA.TXT`.
3. Включить роутер. Первая загрузка может занять несколько минут: драйверы USB/FAT32 должны распознать флешку, а встроенный скрипт `99-heatbridge-usb-setup` — применить пароль и включить Wi-Fi.
4. На телефоне найти Wi-Fi с именем из поля `WIFI_SSID` и подключиться с личным паролем из чата. Если имя не задано, используется `DachaHeat-Setup`. Проверить `http://192.168.1.1/` (LuCI есть только в варианте webui), а также `http://192.168.1.1:8765/` (Dacha Heat Bridge). Вход root, пароль из чата.
5. После подтверждения Wi-Fi и страницы настроек убрать флешку и вернуть ZTE-модем. Лучше перезагрузить роутер после установки модема.
6. Проверить, что интернет Beeline работает через OpenWrt. По умолчанию скрипт ожидает сетевой интерфейс `usb0`. Реальное имя может отличаться (`eth1` и др.) — настройка модема может потребовать ручной правки через Wi-Fi.

**Не нажимать кнопку Reset для повторной загрузки** без проверки: это может сбросить пароль и Wi-Fi.

Проверка работы BALLU не закончена: Dacha Heat Bridge сохраняет заданные значения, но **не отправляет реальные команды приборам**.

## Что делать, если Wi-Fi не появился

Проверить питание и подождать не менее 5 минут. Если `DachaHeat-Setup` не появилось, считать запуск неподтверждённым и прекратить эксперименты. Повторное «заливание» другой прошивки наугад может затронуть заводские разделы. Для ремонта подключать Ethernet/UART и читать консоль загрузчика; см. `RECOVERY_RU.md`.

Этот проект имеет два типа образов:

- WE2026 `sysupgrade.bin`: не предназначен для первого перехода из Keenetic NDMS;
- Keenetic Omni II `factory.bin` (экспериментальный): формат ориентирован на идентификацию нынешней NDMS, но **ZBT WE1626 не тождественен заводскому Keenetic Omni II**; до физического тестирования совместимость не доказана.

Статус образов: **экспериментальные, установка на риск владельца, резервные копии не являются полным дампом flash**.
