# Способ через DACHA.TXT отменён

По решению владельца прошивка теперь запускает открытую Wi-Fi-сеть без пароля и без флешки. Данный документ устарел. Актуальная инструкция: [OPEN_WIFI_FIRSTBOOT_RU.md](OPEN_WIFI_FIRSTBOOT_RU.md).

Первоначальный адрес: `http://192.168.1.1`, сеть `DachaHeat-Setup` (без пароля). Прежде чем включить ZTE-модем, задайте пароль root и защитите Wi-Fi.
