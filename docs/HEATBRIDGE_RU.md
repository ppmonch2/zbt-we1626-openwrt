# Dacha Heat Bridge — встроенный сервер для OpenWrt

## Что встроено

Образы heat-lite и heat-webui содержат веб-интерфейс для четырёх BALLU, сервер uHTTPd/CGI, постоянную конфигурацию в UCI, облегчённые пакеты Mosquitto **без TLS** и клиентские инструменты MQTT, а также поддержку модема ZTE CDC Ethernet.

Заводские имена в прошивке: Холл_Окно, Мансарда, Холл_Лестница, Кухня. Прописанные UUID — **только идентификаторы Яндекс**, не локальные MQTT-ключи.

Доступные функции после включения: просмотр четырёх устройств, переименование, целые температуры от +5 до +30 °C, режимы «Уехал» (+12 °C) / «Еду на дачу» (+22 °C), сохранение данных при перезапуске. Сервер работает в режиме **SIMULATION / real_commands_sent=false**; он не отправляет команды реальным BALLU.

### Почему режим симуляции

У конкретных Transformer DI 4.0 пока не подтверждены локальные MQTT-топики, аутентификация, TLS-сертификаты, надёжное получение обратных подтверждений и адреса устройств. Подмена адреса HOMMYN без этого способна отключить штатную работу. Не выдавать изменение цифры на веб-странице за физический нагрев.

Никаких паролей, учётных данных, сертификатов или возможности доступа через Яндекс при ограничениях Билайна в прошивку не зашито.

## После первого запуска OpenWrt — настройка с телефона

Для предварительного доступа **LAN не нужен**: в версиях с LuCI первый запуск создаёт открытую сеть `DachaHeat-Setup` без пароля, адрес `192.168.1.1`, как указано в [инструкции](OPEN_WIFI_FIRSTBOOT_RU.md). Это режим первоначальной настройки, а не защищённая рабочая сеть.

1. Сразу задать пароль root в LuCI и включить WPA2/WPA3 для Wi-Fi. Пока это не сделано, интернет через ZTE выключен.
2. Включить WAN `wanusb` в LuCI, убедиться, что ZTE распознан. При необходимости поправить интерфейс `usb0` / `eth1`.
3. После защиты Wi-Fi включить Heat Bridge командой `heatbridge-enable` через SSH, затем открыть `http://192.168.1.1:8765/` с учётными данными root.
4. Проверить сохранение названий, уставок и режимов; на экране должно оставаться предупреждение «реальные команды отключены».

Скрипт `heatbridge-enable` не запускает сервер при пустом пароле администратора или незашифрованном Wi-Fi. Первое включение через телефон не гарантировано до проверки загрузчика и аппаратной совместимости.

Mosquitto специально **выключен при первой загрузке**. В этой сборке TLS для MQTT отсутствует: если конкретному BALLU потребуется TLS, взаимодействие через такой брокер без отдельной доработки не заработает. Его включение и подключение BALLU — отдельная задача после проверки протокола. Не включать облачное перенаправление DNS до испытаний.

## Варианты образов

- **heat-lite / heat-webui:** профиль WE2026 для обновления уже установленной OpenWrt; версия без LuCI не подходит для телефонной первичной настройки.
- **omni2-firstflash / omni2-firstflash-webui:** экспериментальный factory-формат Keenetic Omni II, с LuCI во втором варианте. Совместимость с ZBT WE1626 пока не подтверждена.

Система собирается под профиль OpenWrt **zbtlink_zbt-we2026**, который похож на WE1626, но не является подтверждённой точной аппаратной ревизией. Для штатного первоначального перехода с Keenetic наши `sysupgrade.bin` использовать нельзя до проверки загрузчика. См. [RECOVERY_RU.md](RECOVERY_RU.md).
