# Dacha Heat Bridge — встроенный сервер для OpenWrt

## Что встроено

Образы heat-lite и heat-webui содержат веб-интерфейс для четырёх BALLU, сервер uHTTPd/CGI, постоянную конфигурацию в UCI, пакеты Mosquitto с TLS и клиентские инструменты MQTT, а также поддержку модема ZTE CDC Ethernet.

Заводские имена в прошивке: Холл_Окно, Мансарда, Холл_Лестница, Кухня. Прописанные UUID — **только идентификаторы Яндекс**, не локальные MQTT-ключи.

Доступные функции после включения: просмотр четырёх устройств, переименование, целые температуры от +5 до +30 °C, режимы «Уехал» (+12 °C) / «Еду на дачу» (+22 °C), сохранение данных при перезапуске. Сервер работает в режиме **SIMULATION / real_commands_sent=false**; он не отправляет команды реальным BALLU.

### Почему режим симуляции

У конкретных Transformer DI 4.0 пока не подтверждены локальные MQTT-топики, аутентификация, TLS-сертификаты, надёжное получение обратных подтверждений и адреса устройств. Подмена адреса HOMMYN без этого способна отключить штатную работу. Не выдавать изменение цифры на веб-странице за физический нагрев.

Никаких паролей, учётных данных, сертификатов или возможности доступа через Яндекс при ограничениях Билайна в прошивку не зашито.

## После первого запуска OpenWrt — работа IT-специалиста

Нужен **LAN-кабель** для первичной настройки. Первоначальная прошивка может запускаться с выключенным Wi-Fi. Сначала проверить совместимость установленной платы, U-Boot, модема и разметки памяти. Если она не подтверждена, НЕ ПРОШИВАТЬ.

1. Сервисный компьютер по Ethernet к LAN, открыть OpenWrt обычно по `192.168.1.1`. Настроить пароль root командой `passwd` либо через LuCI, если она есть.
2. Проверить интернет через ZTE в режиме CDC Ethernet и настроить интерфейс WAN на найденное USB-соединение. Заранее прописанных Wi-Fi SSID или паролей нет; включить Wi-Fi 2,4 ГГц вручную.
3. По SSH запустить `heatbridge-enable`. Скрипт откажется работать при пустом пароле root, и только после успешной проверки включит отдельную службу uHTTPd.
4. Открыть **http://192.168.1.1:8765/** внутри LAN. Ввести логин `root` и установленный пароль. Нельзя публиковать этот порт в интернет; пароль передаётся через HTTP в защищённой локальной Wi-Fi сети.
5. Проверить сохранение имён, уставок и режима; после перезагрузки проверить сохранённые значения. На экране всегда должна оставаться пометка «реальные команды отключены».

Mosquitto специально **выключен при первой загрузке**. Его включение и подключение BALLU — отдельная задача после проверки протокола. Не включать облачное перенаправление DNS до испытаний.

## Почему есть два варианта

- **heat-lite:** меньше размер образа; без LuCI. SSH, Wi-Fi и интернет требуют ручной настройки IT-специалистом.
- **heat-webui:** содержит LuCI, если вариант уложился в ограничение памяти. Его наличие не гарантирует достаточный writable overlay.

Система собирается под профиль OpenWrt **zbtlink_zbt-we2026**, который похож на WE1626, но не является подтверждённой точной аппаратной ревизией. Для штатного первоначального перехода с Keenetic наши `sysupgrade.bin` использовать нельзя до проверки загрузчика. См. [RECOVERY_RU.md](RECOVERY_RU.md).
