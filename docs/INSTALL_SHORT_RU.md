# ZBT WE1626: короткая инструкция установки и восстановления

**Прошивка экспериментальная.** Мы приняли MT7620N как рабочую гипотезу, получили MTD-разметку от реального устройства, но не проверили команду загрузки U-Boot и работу Wi-Fi на новом ядре. Сам факт успешной сборки в GitHub не является проверкой на роутере.

## 1. Какой файл нужен

Только образ из нового GitHub Actions-процесса [WE1626 custom MT7620N source build](https://github.com/ppmonch2/zbt-we1626-openwrt/actions/workflows/we1626-custom.yml), когда он завершится **Success** и аудит `CUSTOM_PRE_FLIGHT.txt` пройдёт.

Искать файл с окончанием `zbtlink_zbt-we1626-ndms-squashfs-factory.bin`. Не пользоваться ранее выданными `zyxel_keenetic-omni-ii` и `zbtlink_zbt-we2026`.

**Пока не проверен загрузчик, файл не загружать в действующую Keenetic.**

## 2. Проверка перед первой установкой

1. Сохранить штатные файлы `firmware` и `startup-config` на телефон/компьютер; не выкладывать конфигурацию в публичный GitHub.
2. Для безопасной первой установки IT-специалист должен получить дамп SPI NOR (8 MiB), сохранить U-Boot и RF-EEPROM, проверить U-Boot по UART и убедиться, что он умеет загружать uImage с ядром больше старого раздела `Kernel=0x130000`.
3. Провести первый запуск с доступом по Ethernet и UART на рабочем столе, проверить Wi-Fi, модем ZTE `19d2:1225 → 19d2:1405`, реальные границы MTD и доступную память. Если что-либо не соответствует — прекратить установку.
4. Если загрузчик отвергает `factory.bin` или ожидает фиксированный размер ядра — **не обходить защиту и не прошивать наугад**.

## 3. После подтверждённой установки

1. После загрузки с Android подключиться к открытому Wi-Fi `DachaHeat-Setup` (без пароля). Интернет на нём пока отсутствует.
2. Открыть `http://192.168.1.1` и сразу установить пароль `root`, затем WPA2/WPA3 и пароль Wi-Fi в LuCI.
3. Подключить ZTE к USB, проверить интерфейс `wanusb` и после защиты Wi-Fi разрешить WAN. При необходимости поправить физическое имя сетевого интерфейса.
4. Если нужно сохранить подключение к BALLU и Алисе, вручную установить прежние SSID и пароль сети.
5. Heat Bridge — только тестовый сервер уставок. Он **не отправляет команды реальным BALLU** и не решает ограничение Билайна без отдельной сетевой настройки.

## 4. Если после эксперимента роутер не запустился

- При отсутствии Wi-Fi не менять прошивку и не нажимать Reset многократно.
- Отключить роутер и доставить IT-специалисту вместе с резервными файлами; сначала читать журнал U-Boot, затем восстановить прежнюю систему через проверенный UART/TFTP/recovery или SPI-программатор.
- Полный дамп SPI NOR намного надёжнее, чем только `firmware` и `startup-config`. Если он не сделан, возможна отдельная работа по восстановлению заводских калибровок и MAC.

Для специалиста: [подробная карта памяти, загрузчик и технические риски](BOOTLOADER_FLASH_PLAN_RU.md).

**Вывод:** первый шаг — завершить и проверить custom-сборку; второй — подтвердить загрузчик. Без этого «файл готов к прошивке» было бы неверным утверждением.
