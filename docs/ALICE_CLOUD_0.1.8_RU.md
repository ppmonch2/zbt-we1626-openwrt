# Облачное обновление 0.1.8

Совместимо с установленным агентом роутера 0.1.2. Установка на роутере не нужна.
Архив содержит только три Python-файла функции, без ключей и настроек устройств.

## Что изменено

- TLS-соединение для чтения подтверждения открывается одновременно с отправкой
  задания в очередь. Ошибка предварительного соединения не отменяет обычное чтение.
- Положительная проверка владельца переиспользуется до 30 секунд в одном экземпляре
  функции. Проверяется пара «владелец + хеш токена», отрицательный ответ не кешируется.
  Отзыв токена может быть замечен с задержкой до 30 секунд. Кеш ограничен 128 записями.
- Ожидание подтверждения увеличено с 2.65 до 2.8 секунды. Оставшиеся 200 мс — запас
  на накладные расходы платформы; достаточность этого запаса проверяется на живом запросе.
- DONE возвращается только после проверки подлинного подтверждения и совпадения
  заданной температуры/режима. Публикация сообщения в очередь не считается успехом.

Это сокращение облачных задержек, а не доказанное устранение ошибки на реальном
оборудовании. Показ текущей уставки и параллельное выполнение на роутере остаются
незавершёнными: retrievable=false, query возвращает пустые capabilities.

## Установка

1. Скачать downloads/Ballu-Alice-Function-0.1.8.zip из этого репозитория.
2. Yandex Cloud → Cloud Functions → ballu-alice → Редактор.
3. Выбрать загрузку ZIP-архива и загрузить скачанный файл.
4. Точка входа skill.handler, среда Python 3.12. Сохранить существующие переменные
   окружения, сервисный аккаунт и тайм-аут функции 3 секунды. Нажать «Создать версию».
5. На вкладке «Тестирование», тег $latest, «Без шаблона», отправить:

```json
{"heatbridge_diagnostic":"version"}
```

В ответе должно быть version: "0.1.8". Эта проверка не управляет обогревателями.
Затем открыть карточку одного прибора в Алисе и один раз изменить уставку на 1 °C.
Если ошибка осталась, нужен журнал action из тестирования опубликованного навыка:
время отправки, время ответа и action_result. Не повторять команду многократно:
ошибка ожидания всё ещё может означать, что команда уже была выполнена.

Откат: загрузить downloads/Ballu-Alice-Function-0.1.7.zip и создать новую версию
с прежними переменными окружения. Ни обновление, ни откат не меняют привязку аккаунта.
